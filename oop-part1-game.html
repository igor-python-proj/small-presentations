Свой класс — герой игры

Сегодня собираем свой первый класс: героя игры, 1–2 объекта и метод attack, в котором у героя уменьшается энергия. Делаем по шагам — как собирали машину MyCar.

  • Герой: Hero — имя и энергия
  • Действие: attack() — атака тратит 10 энергии
  • Правило: текст, код и схема на каждом слайде — про одно и то же
повторение · класс

Класс — шаблон героя

Класс — это шаблон (чертёж), по которому создаются объекты. Сам класс объекты не создаёт: объект появляется, когда мы вызываем класс — Hero(...).

# класс - шаблон; сам объекты не создаёт
class Hero:
    def __init__(self, name):
        self.name = name
        self.energy = 100

hero1 = Hero("Ария")   # объект из чертежа
hero2 = Hero("Кай")
Чертёж один — карточек сколько угодно. Имя у каждой своё, энергия — как задали в конструкторе.
понятие · конструктор

__init__ — конструктор

Python вызывает конструктор сам — при вызове Hero(...). Внутри self — сам создаваемый объект: слева self.name — атрибут объекта, справа name — параметр.

class Hero:
    # initialize - конструктор; Python вызывает
    # его САМ при Hero(...)
    def __init__(self, name):
        # слева self.name - атрибут объекта,
        # справа name - параметр
        self.name = name
        self.energy = 100

hero1 = Hero("Ария")  # вызов класса → __init__
После Hero("Ария") в памяти живёт объект hero1 с двумя атрибутами.
практика · объекты

Два героя — два объекта

Задание просит 1–2 объекта — делаем двух. hero1 и hero2 — независимые карточки: у каждого свои значения атрибутов. К атрибуту обращаемся через точку.

hero1 = Hero("Ария")
hero2 = Hero("Кай")

# к атрибуту обращаемся через точку;
# у каждого объекта он свой
print(f"{hero1.name}: энергия {hero1.energy}")
print(f"{hero2.name}: энергия {hero2.energy}")
# Ария: энергия 100
# Кай: энергия 100
Имена и значения у карточек разные, а устройство одно — из чертежа Hero.
понятие · метод

attack() — метод героя

Метод — функция внутри класса. Через self он видит атрибуты именно своего объекта: код один, а данные у объектов разные. Атака тратит энергию.

# продолжение: класс Hero - на прошлом слайде

    # метод - функция внутри класса
    def attack(self):
        # атака тратит энергию
        self.energy = self.energy - 10
        print(f"{self.name} атакует! Энергия: {self.energy}")

hero1.attack()
# Ария атакует! Энергия: 90
attack() — действие объекта: вызвали — энергия уменьшилась на 10.
понятие · self

self — этот самый герой

Вызываем hero1.attack() — энергия падает только у Арии. self означает «этот самый объект»: у hero1 это hero1, у hero2 — hero2. Меняется только у того объекта, через который вызвали метод.

hero1 = Hero("Ария")
hero2 = Hero("Кай")

hero1.attack()  # меняется только Ария!
print(hero1.energy)  # 90
print(hero2.energy)  # 100
Кстати: поменять атрибут можно и снаружи — hero1.energy = 1000. Класс это не контролирует, поэтому правильный путь — методы. Как прятать данные правильно — узнаете позже.
Кнопка — иллюстрация к коду слева: каждый вызов hero1.attack() отнимает 10 энергии.
кстати

Всё вокруг — классы

type(hero1) покажет класс Hero. У встроенных типов тоже есть классы: у строки — str, у списка — list. Получается, мы пользуемся классами с самых первых уроков.

print(type(hero1))
# <class '__main__.Hero'>

# у встроенных типов тоже есть классы:
print(type("привет"), type([1, 2, 3]))
# <class 'str'> <class 'list'>
Свой класс Hero устроен так же, как знакомые str и list.
собираем

Весь код целиком

Всё из урока в одном куске — можно скопировать в PyCharm и запустить.

class Hero:
    # конструктор - Python вызывает его сам при Hero(...)
    def __init__(self, name):
        self.name = name
        self.energy = 100

    # метод видит атрибуты именно своего объекта
    def attack(self):
        self.energy = self.energy - 10
        print(f"{self.name} атакует! Энергия: {self.energy}")

hero1 = Hero("Ария")
hero2 = Hero("Кай")
hero1.attack()  # Ария атакует! Энергия: 90
Свой класс — тот же код: поменяйте имя и добавьте своё.
практика · свой класс

Твоя очередь — свой герой

Не обязательно герой: пусть это будет рыцарь, маг или питомец — структура та же.

  • Основное: свой класс персонажа — имя придумайте сами
  • 1–2 объекта: у каждого свои значения атрибутов
  • Метод attack: у героя энергия уменьшается на 10
  • По желанию: метод heal() — возвращает энергию: self.energy = self.energy + 10
hero1 = MyHero("Ария")
hero2 = MyHero("Кай")

print(hero1.name, hero1.energy)  # Ария 100
hero1.attack()
print(hero1.name, hero1.energy)  # Ария 90
print(hero2.name, hero2.energy)  # Кай 100
Справа — проверка, а не решение.
MyHero — заглушка вместо имени класса; attack() и тело — ваши.

Свой класс — это просто

Вся история — про одних и тех же героев: класс один, карточек две, действие одно. Если узнаёшь их в каждой карточке — свой класс уже почти готов.

1 · Класс
Hero — чертёж: какие поля и действия есть у любого героя.
2 · Объект
hero1 и hero2 — заполненные карточки, у каждой свои значения.
3 · Конструктор
__init__ — Python вызывает его сам при Hero(...).
4 · Метод и self
attack() меняет энергию только у того, кого вызвали.

Имя и энергия — данные в объекте, поведение — в методах. В следующий раз разберём, как прятать данные от случайных изменений.
