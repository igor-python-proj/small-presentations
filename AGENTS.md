# AGENTS.md

Репозиторий — набор самостоятельных HTML-презентаций для показа с ТВ. Сборки нет: файл открывается в браузере как есть, GitHub Pages публикует корень `main`.

## Структура

- `oop-partN.html` — одна колода, один самодостаточный файл: CSS и JS внутри, без CDN и внешних ассетов.
- `tools/check-slides.mjs` — локальная проверка вёрстки (каталог gitignored).
- `index.html` — заглушка, не использовать как навигацию по колодам.
- `node_modules/`, `package*.json`, `tools/`, `.serena/` — локальное окружение, не версионируются.

## Контракт колоды

На это опираются навигация и проверка — не ломать:

- слайд — `<section class="slide">`, при загрузке ровно один имеет класс `active`;
- `.slide.center` — слайд с одной центрированной колонкой (титул, итог);
- глобальная функция `go(n)` переключает слайд;
- на десктопе активный слайд не скроллится внутри: контент обязан влезать целиком;
- если задаёшь многоколоночную сетку для `.slide.active`, исключай центр: `.slide.active:not(.center)`, иначе титул уедет в левую колонку;
- декоративные элементы внутри `.slide.center` — только `position: absolute`, чтобы не сбивать центрирование.

## Новая колода

1. Возьми существующую колоду как каркас: разметка, `go(n)`, клавиши, кнопки, свайпы, счётчик и прогресс.
2. Сохрани `lang="ru"`, `meta charset`, `meta viewport`, осмысленный `<title>`.
3. Держи один файл = одна колода; общих CSS/JS в проекте нет, поэтому правки в навигации или каркасе повторяй по файлам осознанно.
4. Назови файл `oop-partN.html`. Для новой серии обнови шаблон `^oop-part.*\.html$` в `tools/check-slides.mjs`, иначе колода не попадёт в проверку.
5. Прогони проверку и пролистай колоду вручную.

## Проверка

```bash
npm install        # если нет node_modules (нужен playwright-core)
npm run check
```

Скрипт листает все колоды на 1280×720, 1366×768 и 1920×1080 и падает при:

- вертикальном переполнении активного слайда;
- горизонтальном скролле внутри `pre`;
- горизонтальном переполнении документа.

Дополнительно открой колоду в браузере и пролистай все слайды: стрелки, пробел, кнопки, точки. Проверь, что ничего не обрезано и не мигает при переключении.

## Стиль

Визуальный стиль не зафиксирован: палитра, шрифты, фоны и иллюстрации — решение конкретной колоды. Инварианты:

- ТВ-первый: крупный текст, высокий контраст, минимум мелких деталей; читаемость с расстояния важнее плотности.
- Один слайд — одна мысль: заголовок и 1–3 тезиса, а не статья.
- Русский язык: «ёлочки», длинное тире, единообразие терминов и подписей внутри колоды.
- Код: короткие примеры, моноширинный шрифт, без горизонтального скролла; подсветка — классами и `span`, без внешних библиотек.
- SVG — инлайновый; декоративный — `aria-hidden="true"`, смысловой — с текстовой подписью.
- Никаких CDN и внешних шрифтов: файл должен работать офлайн и с `file://`.
- Тему колоды задавай через CSS-переменные в `:root` — палитру и размеры проще менять в одном месте.
- Не унифицируй стили разных колод без просьбы: у каждой свой характер.
