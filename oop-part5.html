Декораторы: функция
в обёртке

Питон разрешает класть функции в переменные и передавать их куда угодно. Дальше — приём, который называют декоратором: взять функцию, обернуть её и подменить имя.

КУКЛА 1
сначала главное

Функция — это значение

Строка — это значение, число — значение. Функция — тоже значение. Имя greet — не сама функция, а ярлык на ней. Переприсвоишь имя — ярлык переедет.

def greet(name):
    print(f'Привет, {name}!')

g = greet       # в переменную положили функцию
g('Аня')         # вызвали через новое имя

print(greet)   # <function greet at 0x7f...>
print(g)       # <function greet at 0x7f...> — тот же самый
Главное: функцию можно положить в переменную, в список, передать в другую функцию и вернуть из неё. Это не «особый случай» — это обычное значение в Python.
Два имени — одна функция. Имя — это просто ссылка.
КУКЛА 2
задача

Правило, которое повторяется

Пусть мы хотим считать, сколько раз заказывали пиццу. Правило «запомни и покажи номер» придётся вписать в каждую функцию — и оно размножится.

log = []

def take_order(pizza):
    log.append(pizza)
    print(f'Заказ №{len(log)}: {pizza}')

def deliver(order):
    log.append(order)
    print(f'Доставка №{len(log)}: {order}')
Плохо: счётчик — это не забота заказа и не забота доставки. Это отдельная забота, которая притворяется частью каждой функции. Если функций станет десять — код размножится десять раз.
Одно правило — и оно размазано по всем функциям.
КУКЛА 3
ядро темы

Декоратор — это функция-обёртка

Идея: сделать одну функцию, которая принимает любую функцию, добавляет своё поведение и отдаёт новую функцию. Назовём её wrapper.

log = []

def count_calls(func):          # 1. приняли чужую функцию
    def wrapper(*args, **kwargs):
        log.append('вызов')          # 2. делаем новую функцию
        print(f'Вызов №{len(log)}')
        return func(*args, **kwargs)
    return wrapper               # 3. вернули её наружу
Три шага, и больше ничего: приняли функцию → сделали функцию → вернули функцию. Всё. Декоратор не делает ничего сверх этого — он просто не вызывает func сразу, а готовит обёртку.
Обёртка зовёт настоящую функцию в конце — и отдаёт её результат.
КУКЛА 4
самое важное

Подмена имени

Осталось соединить обёртку с функцией. Python умеет ровно одну вещь: переприсваивать имя. Имя take_order начинает указывать на обёртку — и все вызовы take_order(...) идут сначала в неё.

def take_order(pizza):
    print(f'Готовим {pizza}')

old = take_order                # сохранили старую версию
take_order = count_calls(take_order)   # ← подмена имени

take_order('Маргарита')     # вызов уйдёт в обёртку
old('Пепперони')          # а это — в старую, чистую функцию
Никакой магии: декоратор — это не отдельная возможность Python. Это подмена имени + функция, которая вернула функцию. Старая функция никуда не делась — просто имя теперь указывает на другую коробку.
Имя одно и то же. Коробка под ним — другая.
КУКЛА 5
синтаксический сахар

Значок @ — это короткая запись

Писать take_order = count_calls(take_order) каждый раз неудобно. Python разрешает написать @ над функцией — и делает то же самое. Сначала поняли механизм, теперь можно взять сахар.

@count_calls                  # коротко
def take_order(pizza):
    print(f'Готовим {pizza}')

# Python подставляет вместо этого:
def take_order(pizza):
    print(f'Готовим {pizza}')
take_order = count_calls(take_order)
Читай так: «примени к функции take_order декоратор count_calls». Сигнатура не меняется — вызываешь take_order('Маргарита') как обычно, а лишнее делает обёртка.
@ — это сахар. Механизм ты уже знаешь: подмена имени.
КУКЛА 6
что можно навесить

Обёртка умеет что угодно

Внутри wrapper — обычный код. Значит, обёртка может сделать всё, до чего дотягивается обычная функция.

⏱ замер времени
Запомнить до вызова, замерить после и напечатать, сколько заняло. Идеально для любой функции.
🔢 счётчик вызовов
Считать, сколько раз звали функцию. Наш count_calls — как раз это.
🛡 проверка и лог
Проверить аргументы до вызова, записать, кто и что вызвал, поймать ошибку.
Один и тот же приём — кусок кода, который повторяется, выносится наружу и навешивается на любую функцию. Раньше такое называли «обёртка» — теперь декоратор.
КУКЛА 7
шаг дальше

Декоратор, у которого свои настройки

А если мы хотим не просто считать вызовы, а повторить функцию три раза? Настройка приходит до функции — значит, уровней становится три.

def repeat(times):               # 1. настройка
    def decorator(func):          # 2. сама функция
        def wrapper(*args, **kwargs):  # 3. обёртка
            result = None
            for _ in range(times):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(3)                    # = repeat(3)(greet)
def greet(name):
    print(f'Привет, {name}!')
Читай вложенно: @repeat(3) — это вызов, который возвращает декоратор. Дальше repeat(3)(greet) — вызов декоратора с функцией, и он возвращает обёртку. Три уровня — потому что у декоратора появилась настройка.
Настройка добавляет один уровень — и всё остальное остаётся прежним.
КУКЛА 8
если декораторов два

Порядок: снизу вверх

Декораторов можно повесить несколько. Python применяет их снизу вверх: тот, что ниже, навешивается первым.

@outer
@inner
def take_order(pizza):
    print(f'Готовим {pizza}')

# под капотом:
take_order = outer(inner(take_order))

# вызов идёт: outer → inner → take_order
Читается как луковица: inner оборачивает саму функцию, потом outer оборачивает результат. Поэтому вызов сначала попадает в outer — он снаружи.
Внешний декоратор вызывается первым, внутренний — следом.
КУКЛА 9
подводный камень

Декоратор забывает имя

После подмены take_order указывает на wrapper. Поэтому take_order.__name__ показывает 'wrapper', а документация пропадает. Модуль functools умеет это чинить.

from functools import wraps

def count_calls(func):
    @wraps(func)                # ← одна строка
    def wrapper(*args, **kwargs):
        ...
        return func(*args, **kwargs)
    return wrapper

print(take_order.__name__)   # 'take_order' — без @wraps было бы 'wrapper'
@wraps(func) говорит обёртке: «скопируй имя, документацию и всё остальное из func». Обязательная строка в любом настоящем декораторе.
Одна строка — и функция снова представляется собой.
КУКЛА 10
на будущее

Декоратор может быть и классом

Если обёртке нужно своё состояние (счётчик, кэш, флаг) — удобно сделать её классом. Python вызовет объект, у которого есть __call__, — и это будет вызов функции.

class CountCalls:
    def __init__(self, func):
        self.func = func
        self.count = 0

    def __call__(self, *args, **kwargs):
        self.count += 1
        print(f'Вызов №{self.count}')
        return self.func(*args, **kwargs)

@CountCalls
def take_order(pizza):
    print(f'Готовим {pizza}')
Когда так делают: когда обёртке нужно помнить что-то между вызовами. В остальных случаях хватает обычной функции. Помнишь магию из прошлой части? __call__ — это она и есть.
Объект с __call__ — и есть функция с состоянием.
КУКЛА 11
собираем вместе

Целый пример целиком

Один рабочий файл: считаем вызовы двух функций кухни. Копируйте и запускайте — работает как есть.

Декоратор принимает функцию и возвращает новую функцию.
Подмена имени — единственный трюк: take_order = count_calls(take_order).
@ — короткая запись той же подмены. Порядок — снизу вверх.
*args, **kwargs — чтобы обёртка подходила к любой функции.
@wraps(func) — чтобы не потерять имя и документацию.
log = []

def count_calls(func):
    def wrapper(*args, **kwargs):
        log.append(func.__name__)
        print(f'Вызов №{len(log)}: {func.__name__}')
        return func(*args, **kwargs)
    return wrapper

@count_calls
def take_order(pizza):
    print(f'Готовим {pizza}')

@count_calls
def deliver(order):
    print(f'Везём {order}')

take_order('Маргарита')
deliver('Пепперони')
Код рабочий — нажмите кнопку слева: покажет и попробует скопировать.

Шесть строк — и вся магия

Декоратор — не отдельная фишка Python. Это подмена имени плюс функция, которая вернула функцию. Остальное — украшения.

1 · функция = значение
Её можно хранить, передавать и возвращать. Имя — это ярлык.
2 · обёртка
Приняла функцию → вернула функцию. Внутри — обычный код.
3 · подмена имени
f = deco(f) — вот и весь секрет. Старая функция жива.
4 · @ — сахар
Ровно та же подмена, только коротко. Снизу вверх.
5 · *args, **kwargs
Чтобы обёртка подходила к любой функции.
6 · @wraps(func)
Чтобы не потерять имя и документацию.
Дальше: декораторы с аргументами, декораторы-классы, декораторы свойств (@property) и статические методы. Всё это — та же схема: приняли функцию → вернули функцию.
